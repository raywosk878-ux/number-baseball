# 숫자야구 (모바일 멀티플레이)

## 게임 모드
- **동시 맞히기**: 서버가 정한 같은 비밀 숫자를 모두가 동시에 맞히는 경쟁 (적게 던진 순으로 순위)
- **1:1 대결**: 두 사람이 각자 비밀 숫자를 정하고 번갈아 상대 숫자를 맞힘. 선공이 먼저 맞히면 후공에게 마지막 기회 1번 (같이 맞히면 무승부)
- **여럿이서**: 각자 비밀 숫자를 정하고, 내 차례에 상대 한 명을 골라 공격. 숫자를 들키면 탈락, 마지막 생존자가 승리

방장이 방을 만들 때 또는 대기실에서 모드와 자릿수(3/4자리)를 고를 수 있음.
1:1 대결·여럿이서는 게임 중에 들어온 사람은 관전, 다음 라운드부터 참가.

## 로컬 실행
pip install -r requirements.txt
python app.py   # http://localhost:5000

## Render 배포
1. 이 폴더를 GitHub 저장소로 올리기
2. Render → New → Web Service → 저장소 선택 (render.yaml 자동 인식)
   - Build: pip install -r requirements.txt
   - Start: gunicorn -w 1 --threads 100 -b 0.0.0.0:$PORT app:app
3. 배포된 주소를 휴대폰으로 공유 (방 만든 뒤 '공유' 버튼 → ?room=코드 링크)

※ 워커는 반드시 1개(-w 1). 방 정보가 메모리에 있어서 워커가 여러 개면 방이 갈라짐.
※ 무료 플랜은 15분 무접속 시 잠들어서 첫 접속이 30초~1분 걸림 → 시작 전에 한 번 미리 열어두기.
